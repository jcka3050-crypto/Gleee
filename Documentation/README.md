# 🍰 GleeJeYly - Full Stack Jelly Cheesecake Ordering System

A modern, free-hosted web application for ordering premium jelly cheesecake with a professional fullstack architecture.

**🚀 Deployment:** Frontend on GitHub Pages + Backend on Replit = Fast, free, 24/7 uptime!

---

## ⭐ Key Features

✅ **Browse Products** - View all cheesecake flavors and options  
✅ **Order Management** - Create, view, and track orders  
✅ **Customer Reviews** - Submit and read customer feedback  
✅ **Responsive Design** - Works perfectly on mobile, tablet, desktop  
✅ **PWA Support** - Installable as a mobile app  
✅ **Free Hosting** - $0/month (GitHub Pages + Replit)  
✅ **24/7 Online** - Always available for customers

---

## 📁 Project Structure

```
src/
├── public/           # Entry point (index.html)
├── pages/            # Order, reviews, product, contact, FAQ
├── components/       # Reusable UI components
├── js/               # 16+ modular JavaScript files
├── styles/           # CSS (main + accessibility)
├── data/             # JSON data files  
└── images/           # Product photos and logo
```

**Backend:**
```
src/
├── server/           # Node.js Express API
└── data/             # JSON database storage
```

## 🛠️ Getting Started

### Quick Deployment (10 minutes)

See **[START_HERE.md](START_HERE.md)** for the 3-step deployment guide:
1. Deploy backend on Replit
2. Deploy frontend on GitHub Pages  
3. Connect them together

### Local Development

```bash
npm run dev           # Frontend dev server (localhost:5173)
npm run dev:server    # Backend dev server (localhost:5000)
npm run dev:all       # Both servers together
npm run build         # Build for production
```

## 🏗️ Architecture

**Frontend:**
- HTML5, CSS3, Vanilla JavaScript (ES6 modules)
- Vite build tool for optimization
- PWA with Service Worker offline support
- Mobile-first responsive design

**Backend:**
- Node.js v18+ with Express.js
- SQLite database (fast, serverless)
- REST API with comprehensive validation
- Professional error handling & logging

**Hosting:**
- **Frontend:** GitHub Pages (global CDN, instant updates)
- **Backend:** Replit (24/7 always-online, auto-restart)
- **Cost:** $0/month (free tier on both platforms)
